## 数字下沉消融实验（验证「改数字就一定绕不开」）
- 新增消融开关 ABLATION.layerWords（默认 true）：只关说明文字、不过滤数字，与 yaoLayer 独立，才能分离「数字」与「文字」两个变量。涉 libs/liuyao.js（verdict 三类说明段）+ libs/config.js（「有效作用力」注解行），已同步 miniprogram/utils。
- 实验 2×2 缺一格：ON(过滤+说明) / BARE(过滤无说明) / OFF(未过滤无说明)。12 场景，模块 loveM/loveF/study/child 各 3，12/12 方向翻转。
- 结果：ON 5.42（一致性1.67）/ BARE 5.75（1.83）/ OFF 4.50（1.08）；评审判最优 ON9/BARE3/OFF0；方向一致 ON 9-12、BARE 8-12、OFF 5-10。
- **结论1 推论成立**：下沉到数字锁住事实（OFF 一致性掉 0.6+，被判最优 0 次）。
- **结论2（更有价值）**：BARE 抽掉说明文字后一致性反高于生产 ON —— 「已下沉为数字的东西，连解释它的文字也不必留」，那句「不得改取各爻自身旺衰分重算」在提醒模型去重算。通则补充：下沉为数字后须删掉解释该数字的文字。
- **结论3**：下沉锁死事实、锁不住结论。三失败案例（山雷颐/水地比/乾为天）模型逐字复述净力 −6/−5/−5 仍判吉：放大单项（持世）、给净力重新赋语义、重复计利（引擎 marks 里的 +2 又被抓当论据）。缺「净力为总判、单爻信号仅两可时起作用」的优先级指令。
- **重要自我修正：三条结构规则只有两条真下沉**。合冲刑害次序只写 out.relOrder 与 verdict 文字，effForce 完全不读它，不改任何数字（素材筛选跑出 0 例暴露）。待办：须把「唯一关系」变成能改数字的权值，否则永远是模型可无视的一句话。
- 实验自身 bug 一处：**数字串组**。ABLATION 是模块级全局变量，多场景 Promise.all 并发时 await 之后再读引擎数字会读到别的场景的开关 → BARE 数字等于 OFF。第一轮已作废留档 _buggy.json。修法：设开关→建提示词→读数字放同一同步块；自检加「BARE 数字==ON 数字」断言。
- 硬指标教训：「是否复述本组数字」三组均 11~12/12，饱和无区分度；真正区分度在方向一致性。下轮消融换掉复述类指标。
